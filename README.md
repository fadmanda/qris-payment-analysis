# QRIS Payment Behavior and Purchase Decision Analysis

## Project Overview

This project explores simulated consumer payment behavior and purchase decision patterns related to QRIS.

The project was inspired by a university research assignment on QRIS payment decisions among students. However, the original survey dataset was no longer available, so this notebook uses **synthetic data** created for portfolio and analytical practice.

**The results do not represent real survey respondents or actual consumer behavior.**

## Objectives

* Explore payment preferences and QRIS usage patterns in the synthetic dataset.
* Summarize perceived ease of use, benefits, security, and purchase decision scores.
* Explore relationships between these factors and purchase decision scores.
* Practice data cleaning, exploratory data analysis (EDA), visualization, and regression analysis.

## Tools & Libraries

* Python
* Google Colab
* pandas
* NumPy
* Matplotlib
* statsmodels

## Project Files

* `qris_synthetic_dataset.csv` — synthetic dataset used in the analysis.
* `QRIS_Payment_Behavior_Analysis.ipynb` — notebook containing data preparation, exploratory analysis, visualizations, and regression analysis.

## Methodology

1. Generate a synthetic dataset for demonstration purposes.
2. Check and prepare the data.
3. Conduct exploratory data analysis.
4. Examine correlations between selected variables.
5. Fit an Ordinary Least Squares (OLS) regression model.
6. Review model diagnostics and multicollinearity using VIF.

## Important Note

This is a **demonstration project using synthetic data**. The analysis is intended to demonstrate Python and data analysis skills. It should not be interpreted as evidence about real QRIS users, nor as a reproduction of the original university research findings.
